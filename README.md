# AI Meal Planner

## Overview
AI Meal Planner is a simple web application that helps users generate meal ideas based on their preferences and the ingredients they have at home.

## Features
- Select preferred cuisines
- Enter available ingredients
- Generate meal suggestions
- Simple and responsive interface

## Technologies Used
- HTML
- CSS
- JavaScript

## Future Improvements
- AI-powered meal recommendations
- Nutrition information
- Save favorite meal plans
